## How to run locally

1. Clone the repository
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   ```

   # Windows
   venv\Scripts\activate

   # macOS/Linux
   source venv/bin/activate

3. Install requirements

    pip install -r requirements.txt
